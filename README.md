# Jogo_de_Cartas
Este repositório foi criado com o objetivo de aprender e praticar JavaScript integrado ao HTML e CSS, além de desenvolver lógica de programação e manipulação de elementos no DOM.

## O que já implementei
- Estrutura visual do tabuleiro (somente os espaços que as cartas devem aparecer)
- Cartas representadas como objetos
- Criação dinâmica das cartas no DOM
- Randomização das cartas
- Seleção sem repetição dentro de cada mão
- Distribuição das cartas entre os jogadores

## Problemas que encontrei
- Organização dos conteúdos dentro das cartas (repetição de cartas e exibição)
- Passagem de valores entre funções
- Diferença entre objetos JavaScript e elementos DOM
- Reutilização do mesmo Node em diferentes locais do DOM

## O que aprendi
- `Math.random()` e `Math.floor()`
- `includes()`
- `return` (mais usos)
- `appendChild()` (exigências como um único item DOM)
- `cloneNode()`
- Relação entre dados JavaScript e elementos DOM
