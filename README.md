# Jogo_de_Cartas
Este repositório foi criado com o objetivo de aprender e praticar JavaScript integrado ao HTML e CSS, além de desenvolver lógica de programação e manipulação de elementos no DOM.

Atualmente, o projeto está em desenvolvimento. No momento, estou estudando e planejando a implementação das próximas funcionalidades.

Status:

- Procurando soluções para o problema de exibição das cartas onde uma mão fica com menos cartas do que desejado, provável problema no DOM e referência de um objeto em dois locais ao mesmo tempo.
